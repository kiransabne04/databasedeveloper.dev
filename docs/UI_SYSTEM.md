# UI system

## Design intent
- specialist engineering practice
- dark evidence-console feel without looking like a terminal theme
- high contrast
- restrained mint accent
- spacious typography
- no stock photography
- proof through structure/data, not decorative screenshots

## Tokens
Defined in `src/styles/global.css`.

## Core components
- BaseLayout
- PageHero
- CTA
- CapabilityGrid
- ProblemGrid
- InvestigationWorkflow
- PG14Notice

## UX rules
- one primary CTA: Request an investigation
- one secondary proof CTA: See sample report
- no modal spam
- no aggressive countdown timers
- no fake social proof
- all capability pages return to the same investigation/contact path
